# PyCORN

A script extract data from .res (results) and .zip files generated by UNICORN Chromatography software supplied with AKTA Systems.

Fork includes additonal functions to handle files from Unicorn 7.

## Installation

`pip install git+https://github.com/d0martins/PyCORN.git@master`

## Requirements

- Python 3.x
- optional: matplotlib (for plotting)
- optional: xlsxwriter (for xlsx-output)

## Usage

See pycorn/docs/USAGE_pycorn_module.md
